## ✨ Features & Architecture

### Modern Technical Stack
- ⚡ **Vite 6**: Next-generation lightning-fast dev server and bundler.
- ⚛️ **React 18**: Component-based user interface architecture.
- 🎨 **Vanilla CSS Design System**: Custom dark mode (`#070b09`), high-contrast lime accents (`#9fef00`), typography (`IBM Plex Mono` & `Manrope`), and glassmorphism.
- 🎬 **Framer Motion**: Smooth page loads, view transitions, micro-animations, and interactive carousel.
- 🛡️ **Lucide React**: Clean SVG iconography for security tools, metrics, and social links.

### UX & Accessibility
- 📜 **Active Scrollspy Navigation**: Header links automatically highlight as you scroll through sections.
- ⌨️ **Interactive Project Showcase**: Supports Arrow Key (Left/Right) keyboard navigation and tab switching.
- 📋 **Copy-to-Clipboard Email**: Quick copy button with animated confirmation toast.
- ⬆️ **Scroll-To-Top Button**: Smooth floating back-to-top button.
- 📱 **Mobile First**: Fully responsive layout with scrollable navigation menu.
- 🚨 **Custom 404 Page**: Cyber terminal-themed error landing page.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js (v18+)** and **npm** installed on your system.

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/naziulsiam/aliportfolio.git
   cd aliportfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the dev server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

---

## 🔨 Production Build

To build the production-ready static bundle:

```bash
npm run build
```

The optimized production output will be generated in the `dist/` directory.

### Preview Production Build Locally:
```bash
npm run preview
```
